# Library Management System

## About the Project

The Library Management System is a simple console-based Java application developed as part of a Java Developer Internship Task.

The project is designed to manage books and users in a library. It provides basic features such as adding books, registering users, issuing books, returning books, and checking the availability of books.

The project focuses on understanding and implementing Object-Oriented Programming (OOP) concepts in Java.

## Objective

The main objective of this task is to develop a mini system for managing books and users while gaining a solid understanding of Java OOP concepts.

##  Features

-  Add new books
-  View all available books
-  Add new library users
-  View registered users
-  Issue a book to a user
-  Return an issued book
-  Check book availability
-  Simple menu-driven console interface

## OOP Concepts Used

This project demonstrates the following Object-Oriented Programming concepts:

- **Encapsulation** – Data members are kept private and accessed through methods.
- **Abstraction** – The system separates the internal implementation from the operations provided to the user.
- **Inheritance** – The project structure can be extended using inheritance when required.
- **Polymorphism** – Object-oriented methods provide the foundation for flexible behavior.
